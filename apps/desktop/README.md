# Thoughtforge Desktop

Desktop UI shell for Thoughtforge.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run tauri:dev
npm run tauri:build
```

## Notes

- Frontend stack: React 19 + TypeScript + Vite
- Rust backend entrypoint: `src-tauri/` (Tauri 2 runtime commands)
- This app is the operator surface for SRS-driven execution, context inspection, and agent control.
